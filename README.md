☢️ **NTM Spider Edition** - a fork of HBM's Nuclear Tech Mod for Minecraft **1.12.2.**
Based on **NTM: Community Edition.** Features new content and fixes.

> [!IMPORTANT]
> **ADDICTION**  
> This mod requires the **CTM (ConnectedTexturesMod**) mod as a **dependency**. 
Place the mod in the **folder with the fork.**

> [!NOTE]
> At the moment, the fork is in an active stage of development.
